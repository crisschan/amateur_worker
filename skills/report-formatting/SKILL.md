## Business Report Formatting Guide

### Standard Report Structure

```
# [Report Title]

**Prepared by:** [Author]
**Date:** [YYYY-MM-DD]
**Version:** [1.0]
**Distribution:** [Team / Stakeholders]

---

## Executive Summary
[2–3 paragraph overview of the report's purpose, key findings, and recommendations.
Write this last. Decision-makers may only read this section.]

---

## 1. Introduction / Background
[Context, scope, and objectives of the report.]

## 2. Methodology / Approach
[How data was gathered or analysis was performed.]

## 3. Findings
[Structured findings, using sub-sections, tables, and bullet points.
Lead with the most important finding in each sub-section.]

### 3.1 [Finding Category]
...

## 4. Recommendations
[Numbered list of concrete, actionable recommendations.]
1. [Recommendation] — [brief rationale]
2. ...

## 5. Conclusion
[Brief closing paragraph tying findings to recommendations.]

## Appendices
[Supporting data, raw tables, or references.]
```

### Formatting Rules
- Use **bold** for key terms when first introduced.
- Tables: include header row; align numbers right.
- Charts: always include a descriptive caption beneath.
- Page length: Executive Summary ≤ 1 page; full report ≤ 20 pages.
- Font: body 11–12 pt; headings use hierarchy (H1 > H2 > H3).
- Avoid jargon; define acronyms on first use.
- Every recommendation should map back to a specific finding.
